# 宠物固定动作中文提示词模板

这些模板供程序参数化调用，不允许运营人员针对每一只宠物重新写整段提示词。工作流、动作段落、镜头约束和解剖约束全部固定；每个用户只自动填充一次 `PET_PROFILE_CN`，随后四个动作共用同一个已确认母版和同一份特征档案。

## 自动字段

- `PET_KIND_CN`：当前只开放 `猫`。狗必须使用独立狗母版和狗动作驱动，不能套猫驱动。
- `PET_PROFILE_CN`：从用户原图和已生成母版自动提取的可见特征短句，例如年龄感、脸型、眼色、耳形、毛长、主色、花纹、颈胸毛和尾巴形态。不得描述原图中看不见的花纹。
- `ACTIVE_FRONT_PAW_CN`：由固定驱动决定，猫舔爪当前恒为 `画面左侧的前爪，也就是猫的右前爪`，不交给用户修改。
- `TAIL_SIDE_CN`：由动作安全母版规范固定为 `身体左后侧`。如未来驱动方向改变，应发布新模板版本，而不是运行时自由改词。

`PET_PROFILE_CN` 由快速视觉分析自动生成并缓存，不是人工提示词创作。视觉分析可与图片上传和母版任务并行，不应阻塞用户等待链路。

## 所有猫动作共用前缀

```text
参考图中是同一只需要被动画化的猫。它的可见特征为：{{PET_PROFILE_CN}}。严格保持参考图中的同一身份、物种、年龄感、脸型、口鼻比例、眼睛颜色、耳朵形状、毛发长度、毛量、毛色、可见花纹、颈胸毛、身体比例和三维卡通材质。猫以标准中性坐姿位于暖白色无缝影棚背景中央，双前爪清晰分开并放在地面上，尾巴位于身体左后侧地面。固定镜头、固定构图、固定角色大小、固定背景。
```

## 待机 `cat_idle_v1`

```text

猫始终保持双前爪落地的中性坐姿，缓慢自然地眨眼一次，只有尾巴尖发生非常轻微的放松摆动，随后回到与第一帧完全一致的姿势。头部、身体、四肢和尾巴主体保持稳定。不得走动、转身、抬爪、改变脸型、改变毛色、出现额外肢体、镜头运动、文字、标志或水印。
```

## 舔爪 `cat_lick_paw_v1`

```text
{{COMMON_CAT_PREFIX}}

动作开始时，两只前爪自然、清晰地放在地面上。只有{{ACTIVE_FRONT_PAW_CN}}平稳抬起并靠近嘴部。猫自然伸出舌头，轻柔舔舐这只前爪两到三次，然后完全收回舌头，将同一只前爪平稳放回地面，最终恢复到双前爪落地的初始中性坐姿。

尾巴必须始终位于{{TAIL_SIDE_CN}}的地面上，全程保持静止，不得抬起、不得靠近嘴部、不得遮挡前爪、不得与前腿或前爪融合。除指定前爪、头部和舌头外，身体其他部分保持稳定。不得出现额外肢体、额外尾巴、尾爪融合、毛发缩短、身份漂移、镜头运动、文字、标志或水印。
```

## 喂食猫动作 `cat_feed_v1`

```text
{{COMMON_CAT_PREFIX}}

使用驱动视频中的同一只浅米白色低矮陶瓷猫碗和碗内多粒棕色干猫粮；猫碗、猫粮、暖白色无缝背景和固定镜头属于场景，必须保持驱动中的位置、形状、数量关系与进退场时序，不得生成第二只碗。猫保持坐姿，猫碗从画面正下方平稳进入中央进食区后，猫平稳低头，使鼻口真实进入碗口内侧，在碗内连续做两到三次小幅自然的舔食和咀嚼动作；舌头只能短暂出现在碗内，碗前沿应自然遮挡舌尖。随后猫完全收回舌头、抬头，恢复到双前爪落地的初始中性坐姿；猫碗再沿原路从画面正下方退出，最后一帧不留猫碗或猫粮。尾巴和双前爪不得靠近嘴部，不得遮挡碗，不得与碗、猫粮或舌头融合。不得出现碗外猫粮、额外猫碗、额外肢体、额外尾巴、毛发缩短、身份漂移、镜头运动、文字、标志或水印。
```

该模板使用 `cat-feed-bowl-driver-seedance-v1.mp4` 和 `replace_mode = true`，让 SCAIL 只替换被跟踪的猫，同时保留驱动中的猫碗、猫粮、背景和进退场时序。生成结果是自包含视频，网页不得再叠加 DOM 猫碗或猫粮层。后期叠碗的已否决路线及失败原因仍保留在 `cat-feed-bowl-transition-v1.md` 供回溯。

## 摸头反应 `cat_head_pet_v1`

```text
{{COMMON_CAT_PREFIX}}

猫保持坐姿，轻轻抬起下巴，放松面部并自然闭眼，短暂停留，随后重新睁眼、放低头部并恢复到双前爪落地的初始中性坐姿。视频和网页界面都不得出现人手、手臂、手指、手形图标或“轻点摸头”引导文字。尾巴和四肢保持稳定。不得出现额外肢体、额外尾巴、伸出的舌头、镜头运动、文字、标志或水印。
```

## 调度规则

1. 用户未确认母版“像”之前，四条视频任务一条都不提交。
2. 用户确认后，四个动作从同一张母版独立分叉，不能把一个动作的输出继续喂给下一个动作。
3. 真并行需要四个独立暖 GPU worker。单 GPU 上排四个 ComfyUI 任务只是排队，不是并行。
4. 浏览器点击动作时只播放已经缓存的 MP4，不在点击时现生成。
5. 每个任务保存 `template_version`、母版哈希、模型版本、seed、驱动哈希和输出哈希，确保复现与回滚。
