# 小爪星球宠物互动 POC

这是一个验证「创建宠物形象 + 点击动作 → 播放预制成片 → 自动回待机」的 Web 样片。

- 已实现：灰猫待机、舔爪、喂食、摸头四段视频，以及动作结束后自动回待机。
- 已实现：每段媒体独立加载；主成片失败时自动切换旧视频或交互回退，不会拖垮整场演示。
- 已实现：用户可在页面选择 JPG、PNG 或 WebP 宠物照片；浏览器会在本机完成尺寸预检、3:4 裁切、平滑、色阶量化与轮廓描边，并生成可下载的二维卡通预览。原图不会上传服务器，也不会消耗生成额度。
- 已实现：使用本地预览后，页面切换为该宠物的静态形象，动作进度明确显示为 0 / 4，三个动作按钮会被锁定，避免错误播放灰猫视频。
- 当前限制：喂食还是“一小块猫粮”的临时 POC，正式版本需要替换为“猫碗里装有多粒猫粮”。
- 当前限制：本地卡通预览是二维滤镜效果，不是与小灰同风格的生成式 AI 母版；用户照片对应的待机、舔爪、喂食和摸头视频尚未接入 GPU 生成服务。
- 未实现：持久化照片存储、生成任务队列、猫狗各自的动作工作流、实时 3D、自由旋转。
- 播放时不调用外部生成 API，每次点击不产生生成费用。

四段 SCAIL-2 输出位于 `public/assets/generated/`，可复用的 ComfyUI 工作流和驱动片位于 `workflows/`。
